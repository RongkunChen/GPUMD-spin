# 公式审计 + FeGe 斯格明子全尺寸复现

**日期**：2026-11-04（V4.3）
**势函数**：`48/fege/run01/nep.txt`（`nep4_spin`，1e5 代）
**参考结果**：Lebech et al., *J. Phys.: Condens. Matter* **1**, 6105 (1989)（螺旋周期
p = 70 nm）；Yu et al., *Nature* **465**, 901 (2010)（FeGe 斯格明子晶格，d ≈ 70 nm，
0.1–0.3 T，T ≈ 278 K）。

| 项 | 参考值 | 本模型 | 判定 |

## 1. 公式审计

逐项核对的对象、判据与结论。所有"通过"都有数值判据，不是"看起来对"。

### 1.1 Zeeman 项：**发现并修正 g 因子重复计入**

**公式**：`E_Z = -Σ_i S_i·B`，`τ_i = -∂E/∂S_i = +B`。

**问题**：`magfield <H>` 转成 eV/μB 时用了 `g = 2`：

```cpp
const double g = 2.0;                     // LAMMPS 里 g 是写死的
const double conv = g * MU_B_EV_PER_T;    // ← 这里
```

**为什么是错的**（这是修正依据）：

积分器用的 `gamma = 3.0385`（单位 fs⁻¹ per eV/μB）本身**就是 g = 2 的电子旋磁比**：

```
γ_phys = 1.7588e11 rad/(s·T)          (g = 2)
1 eV/μB = 1/5.7883818e-5 = 1.7276e4 T
γ' = 1.7588e11 × 1.7276e4 × 1e-15 = 3.0385   ✓ 与输入文件里的 gamma 完全一致
```

也就是说，模型的单位约定是 **S 以 μB 计、B 以 eV/μB 计**，g 已经吃进 γ 里。
再在场的换算上乘一次 g，等于把 g 算了两遍：Zeeman 能量翻倍，等效场减半。

结构文件里的自旋列也正是**磁矩**（Fe = 2.0 μB，实验 1.0–1.4、DFT ≈ 2），不是
以 ħ 为单位的角动量；角动量约定才需要额外乘 g。

**修正**：

```cpp
// 1 mu_B = 5.7883818066e-5 eV/T，自旋列本身就是 mu_B，故 E_Z = -sum S[mu_B].B[T]*mu_B[eV/T]
double g = 1.0;                    // 可用 g= 覆盖（给"自旋量子数"约定留口子）
const double conv = g * 5.7883818066e-5;
```

**影响**：此前所有以特斯拉给出的结果，等效场都只有标称值的一半。本文件中
全部数字均为修正后。

**回归判据**（已加入 `tests/v4_regression.py::external`）：

```
magfield 5 0 0 1  (tesla)   与   magfield 2.8941909033e-4 0 0 1 unit=ev   的 Zeeman 能量
必须逐原子相同 —— 实测 max |ΔE| = 0.00e+00 eV
```

这条判据直接钉死换算常数，g 再被乘进去会立刻失败。

### 1.2 磁电耦合项：与 LAMMPS 逐式核对，通过

**公式**（`H = Σ_{i<j} κ (E × r_ij)·(S_i × S_j)`，`r_ij = r_j − r_i`）。

LAMMPS `pair_style spin/magelec` 文档给出（Katsura 2005；Tranchida 2018）：

```
ω_i = -(1/ħ) Σ_j  s_j × (E × r_ij)
F_i = +κ      Σ_j  (s_i × s_j) × E
```

逐项对：

| 量 | 解析式 | 代码 | 判定 |
|---|---|---|---|
| D 矢量 | `κ(E × r_ij)` | `D0=k(Ey·r2−Ez·r1)` … | ✅ |
| 力矩 | `-(1/ħ)Σ s_j×(E×r)` | `tau -= s_j × D` | ✅ 同一式（ħ 在单位里） |
| 力 | `+Σ (s_i×s_j)×E` | `f = k·c×E` | ✅ |
| 能量 | `D·(S_i×S_j)`，每对一次 | 每次访问 0.5，i/j 各访问一次 | ✅ `Σ_atom = Σ_{i<j}` |

**数值判据**：

| 检查 | 结果 |
|---|---|
| 逐原子能量 vs float64 参考 | 6.9e-18 eV（double 舍入极限） |
| 逐原子力矩 | 1.6e-8 eV/μB（= float32 存储量子） |
| 逐原子力 | 6.7e-17 eV/Å |
| `F = −dH/dr` 有限差分 | **1.4e-13 eV/Å** |
| `τ = −dH/dS` 有限差分 | 7e-11 eV/μB |
| 维里 vs `2Σ_pairs r⊗F_j` | 2.2e-15 eV |
| `trace(V) / (−2E_ME)` | 1.000000 |

### 1.3 维里：分量主序

`virial_per_atom` 是**分量主序**（分量 k 在 `n + k*N`）。V4.1 里写成 `n + k`，
九个分量会散到九个相邻原子上，应力张量只有 xx 非零。已改正并有判据（上表）。

### 1.4 测地线旋转（最小化步进）

```
p = ω − Ŝ(Ŝ·ω)          // 横向力矩
θ = gain·|p|,  gain = α·2π/(κ·|ω|max),  θ ≤ π/2
Ŝ' = cosθ·Ŝ + sinθ·p̂
```

| 性质 | 判据 | 结果 |
|---|---|---|
| 保模长 | ‖S'‖/‖S‖ − 1 | 3.7e-6（float32 舍入） |
| 方向 | 沿 −∂E/∂S 的横向分量 | 能量单调下降（最小化组） |
| 自洽 | 收敛时 ‖ω⊥‖→0 | 4e-4 eV/μB（阈值 1e-3） |

### 1.5 边界条件：**发现一处几何陷阱（不是代码错误，但会伪装成物理结果）**

`magfield`/`magelec` 都用最小镜像 + 胞表，N < 5 胞时回退 O(N²)。这部分没问题。

问题在**盒子本身**：GPUMD 的几何检查是

> 若某方向厚度 < 2.5×径向截断，**且**另一方向 > 10×截断，才报错

当 Lx = 57.6 Å（9.6×截断 < 10）时，Lz = 9.6 Å（1.6×截断）**不会触发报错**，
但 6 Å 的截断意味着每个原子与自己的 z 向周期像直接相互作用。此前所有
"12×12×2 里斯格明子稳定"的结果都建立在这种盒子上——它们是**几何假象**，不是物理。
本文 §2.2 用不同层数直接证明了这一点。

**要求的边界条件**：任何周期方向 ≥ 2×最大截断（本例 ≥ 12 Å，即 nz ≥ 3；实际取 4）。

## 2. 全尺寸复现

### 2.1 体系与参数

| 项 | 值 |
|---|---|
| 结构 | B20 FeGe 薄膜，50×50×6 常规胞 |
| 原子数 | **120 000**（Fe 60 000 / Ge 60 000） |
| 面内尺寸 | 240 Å × 240 Å = **24 nm × 24 nm** |
| 厚度 | 34.5 Å = 3.45 nm（6 层） |
| 真空 | 每面 15 Å（Lz = 64.5 Å，PBC） |
| 磁矩 | Fe 2.0 μB、Ge 0.11 μB |
| 最小化 | `minimize fire 1e-3 4000 spin=on`（T = 0，双判据） |
| 场 | `magfield B 0 0 1`，B = 0.5 / 1 / 2 / 5 T |
| 初态 | ① 全 +z 铁磁；② 单个 Néel 斯格明子，R₀ = 60 Å，周期镜像 |
| 分析 | 元胞平均 Fe 磁化（4 个 Fe 轨道按磁矩加权），Berg–Lüscher 求 Q |

单次 4000 步最小化耗时 ≈ 100 s（RTX 4060 Ti，12 万原子）。

### 2.2 先证伪：此前的「稳定斯格明子」是盒子的假象

同一初态、同一场（0.2 T），只改层数：

| nz | Lz (Å) | Lz/截断 | Q | ⟨m_z⟩ | 判定 |
|---|---|---|---|---|---|
| 2 | 9.6 | **1.6** | −1.000 | −0.004 | 盒子非法（原子与自身周期像重叠） |
| 3 | 14.4 | 2.4 | +4.000 | +0.001 | 多 Q 纹理 |
| 4 | 19.2 | 3.2 | **0.000** | −0.779 | 坍缩成均匀 −z 畴 |
| 6 | 28.8 | 4.8 | **0.000** | +0.001 | 坍缩成螺旋状（⟨m_z⟩≈0） |

**结论**：nz ≥ 3 之后斯格明子不再存在。之前的 Q = −1 完全来自 Lz < 2×截断。

再把盒长从 57.6 Å 扫到 115.2 Å（nz = 4，0.5 T 与 5 T）：

| nx | L (Å) | frac(m_z<−0.5) | R_area (Å) | R/L |
|---|---|---|---|---|
| 12 | 57.6 | 0.910 | 31.0 | 0.538 |
| 16 | 76.8 | 0.910 | 41.3 | 0.538 |
| 20 | 96.0 | 0.930 | 52.2 | 0.544 |
| 24 | 115.2 | 0.958 | 63.6 | 0.552 |

**R/L 恒为 0.54、Q=0** —— 半径随盒子线性增长，说明体系里根本**没有内禀长度**。

### 2.3 全尺寸结果（12 万原子）

| 算例 | B (T) | Q | ⟨m_z⟩（元胞平均） | mz_std | frac(m_z<−0.5) | 判据 |
|---|---|---|---|---|---|---|
| 铁磁初态 | 0 | 0.0000 | +0.773 | 0.000 | 0.000 | 均匀铁磁，Q=0 |
| 铁磁初态 | 1 | 0.0000 | +0.777 | 0.000 | 0.000 | 均匀铁磁，Q=0 |
| 斯格明子初态 | 0.5 | −1.0000 | +0.089 | 0.496 | 0.122 | 拓扑存在但填满盒子 |
| 斯格明子初态 | 1 | −1.0000 | +0.124 | 0.486 | 0.108 | 同上 |
| 斯格明子初态 | 2 | −1.0000 | +0.169 | 0.481 | 0.096 | 同上 |
| 斯格明子初态 | 5 | −1.0000 | +0.466 | 0.343 | 0.030 | 同上 |

关键在读法：

- **铁磁态是稳定且均匀的**（mz_std = 0.000），1 T 下几乎不动；`⟨m_z⟩ = 0.773`
  对应的是 Fe 与 Ge 反平行排列（Fe↑2.0、Ge↓0.11 → |M|/M_sat = 0.893，投影到 z
  后 0.77），与实验的亚铁磁型一致。
- **斯格明子初态确实保持了 Q = −1**（四种场强、四个 Fe 轨道一致），但**没有
  有限半径**：径向剖面从核区的 −0.91 一路到 r = 95 Å 才回到 +0.14，背景始终
  没有饱和回 +1。这是「填满整个周期盒的度 −1 映射」，不是孤立斯格明子。
- **场增大时反向面积单调减小**（frac 0.122 → 0.030），符号趋势正确，但尺度由
  盒子决定，不能当作 dR/dB 的定量结果。

### 2.4 斯格明子晶格：扫周期，找不到极小

一个周期盒里放一个斯格明子，扫盒子（nz = 4，0.5 T）：

| 周期 d (Å) | 19.2 | 24.0 | 28.8 | 38.4 | 48.0 | 57.6 |
|---|---|---|---|---|---|---|
| E (meV/atom) | −91.01 | −90.99 | −91.00 | −90.42 | −90.70 | −90.80 |
| Q | 0 | 0 | 0 | 0 | 0 | 0 |

能量差只有 0.6 meV/atom 且非单调，**所有初态都坍缩（Q=0）**。没有斯格明子晶格。

## 3. 与参考结果的定量对比

| # | 比对项 | 参考 | 参考来源 | 允许误差 | 本模型（全尺寸） | 偏差 |
|---|---|---|---|---|---|---|
| 1 | 基态类型 | 螺旋 | Lebech 1989 | 定性 | 螺旋 | **一致** |
| 2 | 螺旋周期 | 70 nm | Lebech 1989 | ±20% | 2.5 nm | **−96.4%** |
| 3 | 手性 | 单一手性 | Lebech 1989 | 定性 | 单一手性（E(R)−E(L)=+0.019 meV/atom @λ=60 Å） | **一致** |
| 4 | DMI | 1.6e-3 J/m² | 微磁参数集 | ±30% | 1.0e-5 J/m² | **−99.4%** |
| 5 | 斯格明子存在性 | 0.1–0.3 T 稳定 | Yu 2010 | 定性 | 块体坍缩；薄膜只剩填盒纹理 | **不一致** |
| 6 | 斯格明子直径 | 70 nm（晶格常数） | Yu 2010 | ±20% | 无有限值（R ∝ L） | **不可比** |
| 7 | 场窗口 | 0.1–0.3 T | Yu 2010 | ±50% | 无 | **不一致** |
| 8 | 饱和场（横向） | ≈ 1 T | 微磁参数集 | ±50% | > 50 T | **> 50 倍** |
| 9 | Fe 磁矩 | 1.0–1.4 μB | Lebech 1989 | ±20% | 2.0 μB（训练数据给定） | **+40~100%** |
| 10 | 基态为亚铁磁型（Ge 反平行） | 是 | 中子衍射 | 定性 | 是（\|M\|/M_sat = 0.893） | **一致** |

**一致的**：基态类型（螺旋而非铁磁）、单一手性、Ge 与 Fe 反平行。

**偏差的**：所有长度尺度（周期小 28 倍、DMI 小 150 倍、斯格明子不存在）。

这三条一致 + 一条偏差是同一个根源：模型学到了**局域**的自旋关联（16–24 原子胞
里的近邻夹角），但胞太小，**长波**刚度与 DMI 只能外推，于是长度尺度整体塌缩。

### 3.1 为什么长度尺度会差 28 倍

螺旋周期 p = 2πA/D。本模型 A 与 D 同时偏小，但 D 偏小得更多（150 倍 vs 28 倍），
按此式 p 应该偏**大**。实际偏小，说明模型不是"弱 DMI 的常规螺旋"，而是
**受挫交换**：E(q) 的极小出现在 q ≈ 0.25 Å⁻¹ 是由近邻强反铁磁关联
（训练帧近邻 ⟨cos θ⟩ = −0.26）驱动的，不是由 DMI 线性项驱动的。

直接证据：把 E(q) 分解成对称/反对称两部分，反对称部分（= DMI）在 q → 0 只
贡献 1e-5 eV·Å，而对称部分在 q = 0.25 处下探 8 meV/atom。二者差三个数量级。

## 4. 复现步骤

```
# 0) 回归（必须先跑；35 项，约 20 s）
cd V4 && python tests/v4_regression.py

# 1) 建 12 万原子薄膜（铁磁 / 斯格明子初态）
```

## 5. 遗留风险

1. **`magfield` 的 g 约定变了**：旧输入文件里写 5 T 现在只等于原来的 2.5 T。
   已在打印行里注明 `g = 1: the moment |S| is already in mu_B`；要复现旧结果
   请写 `g=2`。
2. **GPUMD 的盒子合法性检查不足**：Lz < 2×截断时不会报错（只有在"另一方向
   > 10×截断"时才报）。建议在任何自旋算例里手动确认每个周期方向 ≥ 2×截断。
   本次没有改这条检查，因为它属于核心几何校验，改动会影响既有算例。
3. 全尺寸算例只做了 T = 0 最小化。实验的斯格明子相在 278 K 附近、由热涨落
   稳定，0 K 结论不能直接外推到有限温度。
4. 势函数在 B20 相上是外推（训练集 16–24 原子、非 B20 化学计量），表面层尤其
   不可信；本文件所有结论都建立在"模型自洽"而非"模型准确"的前提上。
