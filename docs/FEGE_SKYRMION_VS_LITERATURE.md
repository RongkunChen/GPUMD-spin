**方法**：V4 的磁矩最小化 + 外场 + 磁电耦合（见 `V4_FIELD_MINIMIZATION_REPORT.md`）
**日期**：2026-11-04（V4.2 修订）

> 算例（12 万原子）取代。核心更正：小胞里"Q=−1 的稳定斯格明子"是 **12×12×2 盒子

## 0. 一句话结论

**模型能给出斯格明子，但长度尺度比实验小约 30 倍。**

用势函数自身的磁性、不加任何注入项，0.2 T 下单个斯格明子最小化后
**Q = −1.000、半径 12 Å**，半径随场单调减小（1 T 时 9.5 Å）——拓扑与
场响应都是对的。定量偏差来自模型的螺旋周期只有 **≈ 25 Å**，而实验是 700 Å。

| 项 | 本模型 | 实验 | 比值 |
|---|---|---|---|
| 基态 | 螺旋，p ≈ 25 Å | 螺旋，p = 700 Å | **0.036** |
| 手性（DMI） | 有，D ≈ 8–10e-6 eV·Å/atom | 1.6e-3 J/m² ≈ 1.4e-3 eV·Å/atom | **≈ 1/150** |
| 斯格明子 | Q = −1.000，d ≈ 24 Å | Q = ±1，d ≈ 20–70 nm | **≈ 1/30** |
| 斯格明子类型 | 手性被选出（一种旋转方向），Néel/Bloch 之分很弱 | Bloch | **不能判定** |
| 场窗口 | 0.2–1 T（T = 0 最小化） | 0.1–0.3 T（T ≈ 278 K） | 同量级 |

斯格明子直径与螺旋周期都由 A/D 决定，两者同时偏小 30 倍、D 偏小 150 倍，
是同一件事的不同侧面，不是两个独立的失败。

> **本节替代 V4.1 中「算不出斯格明子、模型无 DMI」的结论。** 那个结论是三个
> 测量缺陷叠加的产物，逐条列在 §7。

## 1. 势函数与数据集的准确描述

先从 `48/fege/run01/loss.out` 抄准确的数。列名在文件头：

```
generation total L1 L2 rmse_energy_train rmse_force_train rmse_virial_train
rmse_energy_test rmse_force_test rmse_virial_test rmse_spin_train rmse_spin_test
```

| 量 | 训练集 | 测试集 |
|---|---|---|
| 能量 | 2.01 meV/atom | **1.77 meV/atom** |
| 力 | 61.3 meV/Å | **51.6 meV/Å** |
| 维里 | 45.7 meV/atom | **31.6 meV/atom** |
| 自旋（力矩） | 22.5 meV/μB | **21.1 meV/μB** |

（V4.1 写的是「rmse_E = 17.7 meV/atom、rmse_S = 21 meV/μB」：能量那一位把
`1.770e-03 eV/atom` 读成了 17.7 meV，多了一位。自旋的 21 meV/μB 是对的。）

**数据集是 SOC 非共线构型**，这一点决定了后面所有物性：

| 特征 | 实测 |
|---|---|
| 每帧原子数 | 16–24（1 738 帧，10 种 Fe–Ge 组成） |
| 每帧净磁化 \|⟨S⟩\| | 0.11–0.16（即磁矩方向基本无序） |
| 近邻（2.2–3.2 Å）⟨cos θ_ij⟩ | **−0.12 … −0.28**（≈ 100° 的夹角） |
| 次近邻（3.2–4.2 Å）⟨cos θ_ij⟩ | +0.12 … +0.26 |
| 自旋列 | `spin`、`spin_length`、`initial_magmoms`、`spin_forces_vert` |

所以「训练数据没有手性、自旋近共线」是错的：**自旋是强非共线的，而且带 SOC**。
准确的限制是另一件事：**胞只有 16–24 原子**，装不下 p ≈ 70 nm 的长波螺旋，
所以长波刚度与 DMI 只能靠外推，这才是偏差的来源（§3.2）。

## 3. 这些数字是怎么来的

### 3.1 螺旋色散：模型基态是 p ≈ 25 Å 的螺旋

在 3×3×3 个 B20 常规胞（216 原子，14.4 Å）上，沿 [111] 构造 Bloch 型螺旋
`S = cos(q·r) e1 ± sin(q·r) e2`（q = 2π/λ，e1 ⊥ q，e2 = q̂ × e1），
`minimize fire 1e-9 1 spin=on` 只走一步，读第 0 步总能——即未经任何移动的
单点能。左手 L 与右手 R 只差一个符号。

| λ (Å) | q (1/Å) | E_L − E_FM (meV/atom) | E_L − E_R (meV/atom) |
|---|---|---|---|
| 20 | 0.3142 | −7.53 | −0.367 |
| **25** | **0.2513** | **−7.95（最低）** | −0.222 |
| 30 | 0.2094 | −7.36 | −0.137 |
| 35 | 0.1795 | −6.47 | −0.0894 |
| 40 | 0.1571 | −5.59 | −0.0610 |
| 50 | 0.1257 | −4.16 | −0.0318 |
| 60 | 0.1047 | −3.17 | −0.0189 |
| 120 | 0.0524 | −1.07 | −0.00302 |
| 200 | 0.0314 | −0.54 | −0.00086 |
| 400 | 0.0157 | −0.32 | −0.00034 |
| 800 | 0.00785 | −0.27 | −0.00016 |
| 1200 | 0.00524 | −0.25 | −0.00009 |

两条读数：

1. **铁磁不是基态。** 能量在 λ ≈ 25 Å 处最低，比铁磁低 **7.95 meV/atom**。
   实验的 700 Å 处能量只低 0.25 meV/atom，两者差了 30 倍的长度尺度。
2. **色散在 q → 0 处仍有负斜率**，说明铁磁态是鞍点而不是极小——这是
   「有 DMI 无各向异性」时必然出现的螺旋不稳定性，不是数值问题。

### 3.2 手性：E(L) ≠ E(R)，但只有实验的 1/150

m 左/右手螺旋的能量差是一个纯手性量（共面自旋的交换项对它是盲的）。实测
它在整个 λ 区间都不为零、符号一致（L 总是更低），即**模型有确定的 DMI**。

由 `ΔE/atom = 2 D q` 反解长波极限：

| λ (Å) | ΔE/atom (eV) | D (eV·Å/atom) |
|---|---|---|
| 800 | 1.57e-7 | 1.0e-5 |
| 1200 | 8.8e-8 | 0.8e-5 |

取 **D = (0.8–1.0)e-5 eV·Å/atom**，乘以数密度换成微磁单位：
D_micro = n·D = 0.0723 × 9e-6 eV/Å² = 6.5e-7 eV/Å² = **1.0e-5 J/m²**，
文献 1.6e-3 J/m² → **小约 150 倍**。

短波处（λ = 20 Å）的等效值高达 5.8e-4 eV·Å，比长波极限大 60 倍。这说明手性
耦合是**短程、强 q 依赖**的，不能用一个常数 D 概括——与「交换本身就被
16–24 原子胞里的强非共线构型主导」是同一件事的两个表现。

**偏差说明**：训练胞 16–24 原子，最短的周期信息只到 ~5 Å，长波极限靠外推；
SOC 的 DMI 在这么小的胞里只能约束短波分量。要拿到 700 Å 的螺旋，训练集必须
含 100–500 原子、显式螺旋/畴壁的构型。

### 3.3 斯格明子：模型自身的磁性足够撑起拓扑

> **已被 V4.3 推翻**：本节全部基于 12×12×2（Lz = 9.6 Å）的盒子，小于 2×径向截断。
> 换成 nz ≥ 3 后 Q → 0。见 `FEGE_FULL_SYSTEM_AND_FORMULA_AUDIT.md` §2.2。

12×12×2 常规胞（2304 原子，57.6 × 57.6 × 9.6 Å），初态是解析斯格明子
`θ(ρ) = 2 arctan(R₀/ρ)`，绕 z 轴转过的方位角为 `γ`（γ = 0 是 Néel，
γ = ±90° 是 Bloch 的两种手性）。`minimize fire 1e-3 1500 spin=on`，
**不注入任何 DMI**（κ = 0），0.2 T 沿 +z：

| γ | 类型 | R₀ = 6 Å | R₀ = 15 Å |
|---|---|---|---|
| 0° | Néel | **Q = −1**，R = 8.5 Å | **Q = −1**，R = 11.6 Å |
| 45° | Bloch | — | Q = 0（解绕） |
| 90° | Bloch | Q = 0（解绕） | Q = 0（解绕） |
| 135° | Bloch | — | Q = 0（解绕） |
| 180° | Néel | — | **Q = −1**，R = 11.5 Å |
| 225° | Bloch | — | **Q = −1**，R = 14.6 Å |
| 270° | Bloch | — | **Q = −1**，R = 15.7 Å |

三件事：

1. **斯格明子是真实的亚稳态**，不是初态残留：R₀ = 6 Å 与 15 Å 两个初态都收敛
   到同一个拓扑，且 γ = 90° 在同样两个初态下都解绕——说明这个判据对初态尺寸
   不敏感，只对旋转方向敏感。
2. **手性被选出**：γ ∈ {45°, 90°, 135°} 全部解绕，{225°, 270°} 存活。这与
   §3.2 的「L 螺旋能量更低」是同一件事的两个侧面。
3. **Néel/Bloch 之分很弱**：对同一个 θ(ρ) 只改 γ 做单点能，七种 γ 的总跨度只有
   **0.57 meV/atom**，最低在 γ = 270°。也就是说，模型能选出旋转方向，但选不出
   纹理类型。实验 FeGe 是纯 Bloch，本模型给不出这么强的选择——与 D 比实验小
   150 倍一致。

**半径与场**：γ = 0 时，0.2 T 给 R = 11.6 Å，1.0 T 给 R = 9.46 Å，方向与实验的
dR/dB < 0 一致。直径 24 Å 对实验的 20–70 nm，小 10–30 倍，与螺旋周期小 28 倍
是同一个 A/D 误差。

### 3.4 场响应

κ = 0，从铁磁初态加场最小化（T = 0），M 随场转向并在 50 T 饱和
（cos(M,B) = 0.9976，ΔE 与 −M·B 相对误差 1e-4，见主报告）。饱和场 ~20 T
量级，比实验的 ~1 T 高一个半数量级。

## 4. 对照实验：手工注入 DMI

用 V4 的磁电耦合注入 DMI（`magelec κ E`，D_ij = κ(E×r_ij)，Néel 型），
其余不变：

1. **符号机制正确**：E 沿 x、螺旋沿 z 时，E(+q) 与 E(−q) 可分辨，差值随 κ
   线性增大——这正是势函数自带的那一项，只是在量级上被放大。
2. **拓扑正确**：κ 超过 κ_c ≈ 2e-4 后 Q = −1.000（整数）。
3. **结构正确**：同一个拓扑荷算法在解析斯格明子上给 |Q| = 1.000000、
   在铁磁态给 Q = 0.000000、半径回读误差 < 1 个晶格常数（见
   `tests/v4_regression.py::topology`）。

注入实验的意义是「把 D 放大到文献量级后，代码能否给出正确拓扑」。答案是能。
但注意：**这不是复现实验的途径**，注入的 D 与势函数的 D 是两套参数，
混在一起的相图没有物理意义。

## 7. V4.1 的三个测量缺陷（为什么当初得出「无 DMI」）

原结论「|D| < 5.4e-8 eV·Å、p > 55 μm、斯格明子必然坍缩」是三个独立缺陷叠加：

| # | 缺陷 | 后果 |
|---|---|---|
| M1 | **±q 构造退化**：`e2 = q̂ × e1` 随 q 一起翻号，`sin(φ)·e2` 不变，于是 +q 与 −q 生成的是**同一个构型**。测出来的「E(+q) = E(−q)」是恒等式，不是物理。 | DMI 上界是假的 |
| M2 | **只测了 Bloch 极化**。B20 的 DM 矢量方向与本模型的耦合方向不同，Bloch 纹理对该项不敏感；正确的探针是两种极化都做。 | 系统性低估手性 |
| M3 | **只试了一个螺旋度**（γ = +90° 的 Bloch）就断言「坍缩」。同一个算例改成 γ = 0 直接得到 Q = −1；斯格明子对旋转方向敏感，单点探针会把「这个手性不稳」误读成「没有拓扑」。 | 「必须注入 κ ≥ 2e-4」是假象 |

三条的共同点：**对称性选错了，测到的是恒等式而不是物理量**。修正后的判据
（`dmi_scan.py` 里的 `assert` 会直接拦住 M1）已经写进回归测试。

## 8. 本次比对没有做的事（避免过度声称）

- 没有在有限温度下做相图（实验的 0.1–0.3 T 窗口在 T ≈ 278 K，本工作是 T = 0
  最小化）。原因是模型 T_c 本身不准（Fe 的同类模型偏差 ≈ −9%…−18%）。
- 螺旋周期是从 12 个离散 λ 的网格上取的，分辨率 ±20%；没有做抛物线拟合，
  因为色散在 q → 0 处非解析（DMI 线性项主导）。
- 没有把 κ 换算成「等效 DMI 的物理单位」——磁电耦合是外部注入项，不是势函数
  的一部分，换算只会制造一个看似定量、实则任意的数字。
