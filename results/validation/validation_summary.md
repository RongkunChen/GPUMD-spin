## 0. 一句话结论

模型的**静态磁性**可信：晶格常数 2.8254 Å（−1.4%）、基态磁矩 2.417 μB（+9.9%）、
FM 在 9 种磁构型中能量最低、交换参数自洽。
**声子在换掉内置模块之后也能算了**：自建有限位移 IFC2 + 外部 Python 求解器给出
0 虚频、超胞/位移收敛到 0.005/0.021 THz 的色散，并测出 **H、P 的三重简并**、
**$\Gamma$–P 上 TA 双重简并**和 **FM→DLM 在 N 点 2.24 THz（4.8σ）的软化**。

仍不可用的三处，全部是**模型/代码缺陷**而非"没算"：

1. 内置 `compute_phonon` 与 `minimize` 在 $S=0$ 极限下求值（FM 与 $|S|=0$ 输出逐字节相同）；
2. 模型整体偏硬： $B_0$ +82%、 $v_L[001]$ +52%、 $D$ +8–23%，是同一个系统偏差；
3. SLLG-Langevin 采样器的稳态依赖时间步（900 K 下 dt 0.05→2 fs 使 $|M|$ 1.54→0.16），
   所以 $T_c$ 只能是 PARTIAL。

## 6. 阶段 E：声子（改为外部 Python 求解器，结果可用）

### 6.1 为什么不能再用内置 `compute_phonon`

已经查明根因并保留证据：`force.cu::compute_single_potential` 调用的是**不带
`atom.spin`** 的 `Potential::compute` 重载，所以 Hessian 在 $S=0$ 极限下求值。
实测：**FM 胞与 $|S|=0$ 胞的 `omega2.out` 逐字节相同（md5 一致）**，且内置模块
对 bcc Fe 给出 61.9 THz 的非物理频率、超胞不收敛。状态 **FAIL**（数值不可用）。

### 6.2 替代方案：有限位移 + 自旋感知的力（本阶段新建）

`dump_xyz ... force` **是**自旋感知的（同一位移下 FM 给 −0.1569 eV/Å，
$|S|=0$ 给 −0.1081 eV/Å）。据此在 `scripts/phonon_fd.py` 里自建：

* bcc **原胞**（1 原子 → 正好 3 条声学支）， $7\times7\times7$ 超胞 = 343 原子，
  最小面间距 13.99 Å > $2r_c=12$ Å；
* 只位移一个原子、3 方向、 $\pm\delta$（ $\delta=0.02$ Å）→ 6 次单点；
* 立方对称平均（48 个操作）+ 声学求和规则（ASR）修正；
* $D(q)=(1/m)\sum_R\Phi(R)e^{i\mathbf q\cdot\mathbf R}$，本征值 → $\omega$（15.6333 因子）。

**必须写下来的两个数值事实**：

| 量 | 值 | 含义 |
|---|---|---|
| ASR 修正量 | **0.340 eV/Å²**，占自位项 **2.06%** | 修正前 $\omega(\Gamma)=-1.219$ THz（三重），修正后 $1.0\times10^{-7}$ THz |
| 修正的来源 | 模型 float32 力噪声（完美晶体上 $\max\lvert F\rvert=1\times10^{-4}$ eV/Å） | 远壳层贡献随 $1/\delta$ 变化（ $\delta$: 0.01→0.1 时 1.16→0.13），**不是物理** |

## 7. 阶段 F：声子拓扑（已做，结论是"简并是受对称性保护的，没有 Chern 数"）

在自建的 $D(q)$ 上做（`scripts/phonon_topo.py`）：

**简并结构**（ $31^3$ 网格 + $\Gamma$–P 上 101 点扫描）：

* **H 与 P 是精确的三重简并**。这不是巧合：对任何具有立方对称 + 反演的力常数矩阵，
  在这两个波矢上每个壳层的贡献都是各向同性的（ $D(Q)\propto \mathbb{1}$），
  因此三重简并由**对称性保护**；
* 沿 **$\Gamma$–P（[111]）** 两支 TA 简并（ $C_{3v}$），LA 在其上方；
* N 点分裂为 2+1；
* 网格上带 1–2 的最小间隙为 0（在 [111] 轴上），带 2–3 只在 P 点为 0。

**Berry 相位**（Wilson 环，闭合到最后一点；规范不变性到 $10^{-16}$）：

| 环（圆心 (0.25,0.25)，半径 0.18， $2\pi/a$） | 环上最小间隙 | Berry 相位 | 采样 30/60/120 点 |
|---|---|---|---|
| $k_z=0$ | 0.132 THz | **0** | 一致 |
| $k_z=0.25$ | 0.583 THz | **$\pi$** | 一致（模 $2\pi$） |
| $k_z=0.5$ | 0.882 THz | **0** | 一致 |

**解释**： $k_z=0.25$ 的环**套住了 $\Gamma$–P 轴**（圆心正好在该轴上），那里两支 TA
简并，绕一圈两支互换 → 单带相位 $\pi$，而双带总相位 $2\pi\equiv0$。
所以这里**没有非平庸的拓扑不变量**，只有对称性导致的带交换。

**Chern 数：不给。** 三条声学支在 $\Gamma$（三重）与 H、P 处相接，全环面无完整带隙，
任何整数赋值都是未定义的。`phonon_topology_report.json` 里写明 `chern_numbers: null`。

## 8. 阶段 G：磁–声耦合

### G1 交换致伸缩（PARTIAL，数值已在上一轮给出）

$g_1=72.9$ meV/Å（三种差分 72.9 / 89.3 / 68.8，最大相对差 **23%** > 20% 判据）。
拉伸使 $J_1$ 增大（ $dJ_1/da>0$）。差异来自 $J_1(\varepsilon)$ 的非线性。

### G2 FM–DLM 声子频移（本轮解锁，PASS）

同结构、同体积，FM 与 4 个独立随机自旋构型的声子谱（ $6^3$ 超胞， $\delta=0.02$ Å）：

| 点 | FM (THz) | DLM (THz) | $\Delta\omega$ | 信噪比 |
|---|---|---|---|---|
| $\Gamma$ | 0, 0, 0 | 0, 0, 0 | 0 | — |
| **N（最低支）** | **5.760** | **3.512** | **+2.244** | **4.8σ** |
| N（另两支） | 7.117 / 11.235 | 7.221 / 11.233 | −0.104 / −0.001 | 不显著 |
| H | 10.281 ×3 | 9.818 ×3 | +0.463 | 5.1σ |
| P | 9.189 ×3 | 8.985 ×3 | +0.204 | 1.4σ（不显著） |

全线平均 $\lvert\Delta\omega\rvert=0.44$ THz，最大 2.24 THz。
**最强的软化正好出现在 N 点的最低支**，与 Körmann et al., PRL 113, 165503 (2014)
对 bcc Fe 在 DLM 态下 TA(N) 强软化的结论方向一致（定性比较，未数字化其数据）。

注：分支配对按同一 q 下的排序，遇到交叉会串行；表里只引用高对称点（交叉少）。

### G3 磁子–声子线性混合（NOT_SUPPORTED，不变）

模型唯一的自旋–晶格耦合是交换致伸缩型（对自旋双线性、对位移线性 → 两磁子一声子），
无 SOC（全局旋转能量不变到 $1.3\times10^{-6}$ eV）。故不存在一磁子–一声子反交叉，
$\lvert g\_{mp}\rvert=\Delta E\_{\rm gap}/2$ 不适用。

### 13.1 弛豫（`relax_and_phonons.py --stage relax`）

`minimize` 不能用（它在 $S=0$ 极限求值，见 §6.1），所以用**自旋感知的能量扫描**：
粗扫 0.02 Å + 局部 5 点细化（0.003 Å），二次拟合顶点即 $a_0$。
超胞必须宽于 $2r_c=12$ Å，第一版用 8 原子胞得到 2.8368 Å 的"错误巧合"，已改。

| 磁态 | 胞 | 原子 | $a_0$ (Å) | $E$ (eV/atom) |
|---|---|---|---|---|
| FM | 原胞 7³ | 343 | **2.8368** | −0.27760 |
| NC-90（两子晶格 90° 倾斜） | 常规 5³ | 250 | **2.8292** | −0.10644 |
| AFM-A（(001) 面反铁磁，周期 2a） | 4 原子胞 5³ | 500 | 2.8394 | −0.08422 |
| DLM（随机自旋，3 组平均） | 原胞 7³ | 343 | **2.8466** | −0.07001 |
| AFM-G（最近邻反平行） | 常规 5³ | 250 | 2.8946 | +0.21617 |

**与阶段 B 的 $a_0=2.8254$ Å 差 +0.011 Å**：B1 用的是 2.70–3.00 Å 全区间四次拟合，
在这条硬曲线上顶点被拟合形式带偏；局部二次 + 0.003 Å 网格是本轮采用的值，
声子全部在这个 $a_0$ 上算。对实验 2.866 Å 的偏差从 −1.42% 变成 **−1.0%**。

对共线磁态， $\max|F|$ 恒为零（每个原子都在反演中心），所以平衡判据只能是
$\mathrm{d}E/\mathrm{d}a=0$，不能拿力残差当判据。

### 13.2 修正上一轮的一个真实错误（B3）

上一轮的 `is_b` 子晶格判据 `all(|frac%1-0.5|<0.25)` 在 4×4×4 常规胞上只命中了

|---|---|---|
| **FM** | **0** | 0 |

### 13.4 磁子谱（`figures/magnon_dispersion_lswt.png`、`magnon_phonon_crossing.png`）

**不依赖交换拟合的直接测量**：8×8×8 **常规**胞（1024 原子）上做冻结自旋螺旋，

$$
\hbar\omega(\mathbf q)=2S\ \frac{E(\mathbf q)-E(\mathrm{FM})}{N},\qquad S=m/2=1.2085
$$

**两个必须写下来的坑（都改过了）**：

1. **波矢必须与超胞共格**。 $8^3$ *原胞*盒沿立方轴只有 $4a$ 长，共格步长是
   $2\pi/(4a)$ 而不是 $2\pi/(8a)$；第一版用了 $2\pi/(8a)$，一半的 $q$ 点螺旋在
   周期边界断裂， $\omega(q)$ 非单调（ $m$=1 给 181 meV、 $m$=2 只给 127 meV），
   $D$ 被算成 1347（4 倍）。改用 $8^3$ 常规胞后 $\omega$ 单调。
2. **$D$ 要在 $q\to0$ 外推**。直接对 $\omega$ 关于 $q^2$ 做斜率会被四阶项压低
   （388 vs 434）。

| 量 | 值 |
|---|---|
| $\omega_{\max}$（ $H$ 点，直接法） | **818.5 meV**（= 1219.8 / $S^2$，§15 更正） |
| $\omega(q)$ 序列（ $m$=0…8） | 0, 33.0, 126.9, 271.7, 467.6, 716.9, 972.5, 1155.4, 1219.8 |
| 刚度 $D$（ $\omega/q^2$ 外推到 $q\to0$） | **290.9 meV·Å²**（= 433.7 / $S^2$） |
| 刚度 $D$（直接对 $q^2$ 斜率，naive） | 260.3 meV·Å² |
| 刚度 $D$（LSWT，补上 $S$ 后） | 258.8 meV·Å² |
| 阶段 C 原报告值 | 345.5 meV·Å²（**当年误判为漏乘 $S$；实际应除以 $S$，得 285.9**） |
| LSWT（无 $S$）/直接，8 个共格点 | **0.823 ± 0.015**（两者带同一个错因子，故比值仍对） |

**$0.823$ 就是 $1/S=1/1.2085=0.827$**：阶段 C 的 $\omega=[J(0)-J(q)]$ 少了自旋大小因子，
整条磁子支低了 21%。补回 $S$ 后 LSWT 给 385.9，与直接法的 naive 斜率 388.1 一致到 0.6%，
说明交换拟合本身是自洽的；差别只在 $q\to0$ 的四阶修正（434 vs 388，12%）。

因此**磁子刚度的权威值是 434 meV·Å²**，比参考区间 280–320 高 **+36%**（此前按 345.5
报的 +9% 偏乐观）。

### 13.5 磁–声耦合强度（`H4`）

线性（一磁子–一声子）顶点 $C=\partial^2E/\partial u\ \partial S_\perp$，
用 $\pm\theta$ 对称差分（保持 $|S|$ 不变，否则会漏进纵向通道）：

| 通道 | $C$ (eV/(Å·μB)) | 判读 |
|---|---|---|
| **弹性对照**（完全不改自旋） | $4.8\times10^{-4}$ ± $1.0\times10^{-3}$ | 这就是模板的噪声底 |
| 横向（磁子通道） | $-2.0\times10^{-3}$ ± $1.4\times10^{-3}$ | **与噪声底同量级 → 未分辨** |
| 纵向（ $\vert S\vert$ 通道） | $2.2\times10^{-3}$ ± $1.9\times10^{-3}$ | 同样未分辨 |

噪声底这么大是因为 $\Delta E=C\cdot4\delta u\ \delta\varepsilon\sim10^{-6}$ eV，
已经到 float32 总能噪声。**结构上它必须是零**：共线态下能量只通过
$\mathbf S\_i \cdot \mathbf S\_j$ 依赖自旋，单原子横向转动在角度上是偶函数，
线性顶点恒为零；这也正是 G3 的结论（无 SOC ⇒ 只有双线性耦合 ⇒ 两磁子一声子）。

**真正的耦合有两个可测的量**（都已给出）：

* 交换致伸缩 $g=\partial J/\partial r=\mathbf{72.9}$ meV/Å（G1，三种差分散布 23%）；
* 自旋无序对声子的修正：N 点最低支 **5.760 → 3.512 THz（ $\Delta=2.24$ THz，4.8σ）**，
  H 点 0.46（5.1σ），P 点 0.20（1.4σ，不显著）；
  相对量 $\lambda=\Delta\omega/\omega_{DLM}$ 在 N 点 **0.64**。

### 13.6 避免交叉（`H5`、`figures/magnon_phonon_crossing.png`）

磁子 $Dq^2$ 与声学支 $vq$ 的交点 $q^*=v/D$ 落在很小的 $q$（用补上 $S$ 后的磁子曲线）：

| 方向 | 交叉支 | $q$ (Å⁻¹) | $q$ ($2\pi/a$) | 能量 |
|---|---|---|---|---|
| [001] | TA（双支） | 0.0734 | **0.033** | **2.27 meV** |
| [001] | LA | 0.1263 | **0.057** | **6.77 meV** |
| [111] | TA（双支） | 0.0681 | 0.031 | 1.95 meV |
| [111] | LA | 0.1322 | 0.060 | 7.37 meV |

这些是**精确交叉，不是避免交叉**：两个扇区在共线态下严格解耦，没有排斥。
由此可以给出反交叉能隙的上界

$$
\Delta_{\rm gap}\le 2|C|\ u_{\rm zp}\approx 8\times10^{-3}\ {\rm meV},
$$

比声子线宽低三个数量级——即使把测到的 $|C|$ 全当真，图上也不可能看出反交叉。

## 15. 交换常数 J 与磁子频率：一次真实的因子错误，以及更正后的结论

### 15.1 问题从哪来

用户指出"J 与实验结果相差有点大"。模型给出的 J1 = 55.5 meV（最近邻，8 个），而
第一性原理文献（Liechtenstein 方案，KKR，见 cond-mat/0501713 里用于 bcc Fe 的那套参数）
是 **J1 = 36.34、J2 = 20.65、J3 = −1.63、J4 = −2.40 meV**（同样约定：单位长度经典自旋，
ℋ = −½Σ J S·S）。表面上差 53%，确实需要查。

> **后记（见 §16）**：这 53% 里没有物理，全是口径——55.5 是"单位矢量约定 + 模型自身
> 2.44 μB"，36.34 是"标准约定 + 2.2 μB"。换算到同一口径是 **41.4 vs 36.34（+14%）**，
> 而同一方法用第 2 轮的旧模型得 39.2（+8%）。方法本身的不确定度约 ±30%。

查下来有三件事，一件是错的，两件不是：

| 检查 | 方法 | 结果 |
|---|---|---|
| 1. 拟合本身有没有算错 | 条件数、参数协方差、残差 | 没有。cond(A)=267，σ(J1)=1.8 meV，残差 0.41–0.82 meV/atom |
| 2. **磁子频率/刚度的换算因子** | 重新推导 + 冻结晶格 SLLG 直接测进动周期 | **错了：乘了 S，应除以 S，差 S² = 1.49** |
| 3. J 与文献差 53% 是否真实 | 换算到同一约定、同一磁矩后比较 | **一部分是约定/磁矩，一部分是真实的壳层分布差异** |

### 15.2 错在哪：ħω 的换算

模型算的是"给定自旋矢量时的总能量"，自旋模长是 m = 2.44 μB，即 S = m/2 = 1.22 ħ。
拟合给的是**单位矢量**系数（A 矩阵用 0.5(z_n − S_n(q))），所以

    J_fit = J^S · S²      (J^S 才是 ℋ = −½Σ J S_i·S_j 的标准系数)

Holstein–Primakoff 给 ħω(q) = S[J^S(0) − J^S(q)]，代入上式：

    ħω(q) = [J_fit(0) − J_fit(q)] / S = 2[E(q) − E(FM)] / (N·S)

而代码里写的是 `2·S·[E(q)−E(FM)]/N`，**方向反了**，多出 S² = 1.49。
同一个错误也进了 D 的闭式：正确的是 D = (1/(6S))Σ J_fit z_n r_n²，代码写的是 (S/6)Σ。

**为什么两条"独立"路线都没发现**：冻结螺旋和 LSWT 都用了同一个 2S，所以它们彼此一致
（比值 0.98–1.00），一致性检查对"共同的约定错误"完全无效。这是本轮最该记住的教训。

### 15.3 怎么定的：让模型自己转起来

不依赖任何 Heisenberg 映射，直接测进动周期（`tools/physics_validation/frozen_magnon_test.py`）：

* bcc Fe，5×5×5 常规胞（250 原子），沿 z 加一个长波倾斜 S_x = m·sin(ε cos qz)，ε=0.005；
* **冻结晶格**（xyz 加 group 列 + `fix 0 1`），只让自旋动——否则保守 SLLG 会持续
  把能量泵进晶格（这是已知缺陷 F19：第一次尝试 25 fs 内晶格就升到 52 K，磁子被冲掉）；
* α=0、T=0，ħω = 4.1357/周期[ps] meV。

| q (Å⁻¹) | 实测 ħω | 公式A `2S·ΔE/N`（原代码） | 公式B `2ΔE/(N·S)` | 实测/A | 实测/B |
|---|---|---|---|---|---|
| 0.4433 | 60.9 meV | 84.8 | **56.9** | 0.72 | **1.07** |
| 0.8866 | 195.2 meV | 318.8 | **213.9** | 0.61 | **0.91** |

A 系统性高 30–40%，B 在 ±10% 内。剩下的 7–9% 不是常数因子（两点推出的 S_eff 分别是
1.14 和 1.34，不自洽），所以它不是约定问题，而是这个势的角向能量并非严格双线性
（拟合残差 0.4 meV/atom 也说明这一点）。结论：**换算用 B，即除以 S。**

### 15.5 J 与文献的比较：换算到同一约定之后

J 的**拟合值本身没错**（55.5 meV 这组数一直是对的），错的是"它代表什么"。三种写法：

| 约定 | 定义 | gen_500k J1 |
|---|---|---|
| `J_fit`（拟合原始量） | ℋ = −½Σ J_fit e_i·e_j，e 为单位矢量，自旋模长 = 模型自己的 2.44 μB | 55.5 meV |
| `J^S`（标准 Heisenberg） | ℋ = −½Σ J S_i·S_j，\|S\| 以 ħ 为单位，S = 1.22 | 37.2 meV |
| `J^S@2.2`（实验磁矩） | 同上，但把螺旋自旋缩放到 2.2 μB 重拟合（S = 1.10） | **41.4 meV** |

文献值 36.34 meV 指的是第三种（DFT 基态，磁矩 2.2 μB）。所以**可比的是 41.4 vs 36.34，
高 14%**，不是 55.5 vs 36.34（+53%）。

壳层逐项（gen_500k，@2.2 μB）：

| 壳 | 本文 (meV) | 文献 (meV) | 差 |
|---|---|---|---|
| J1 (z=8, r=2.46) | 41.4 | 36.34 | +14% |
| J2 (z=6, r=2.83) | 2.2 | 20.65 | **−89%** |
| J3 (z=12, r=4.01) | −2.5 | −1.63 | 同号 |
| J4 (z=24, r=4.70) | 0.65 | −2.40 | 符号相反 |
| J0 = Σ z_n J_n | 315 | 337 | −7% |

**J1 只高 14%，但 J2 小一个量级、J4 符号相反。** 也就是说：这个势把交换几乎全部压在
最近邻上，第二近邻几乎没有贡献；而 DFT 的 bcc Fe 有很强的 J2。两者 J0 只差 7%、D 也
对得上（295 vs 298），是因为 J1 偏大恰好补偿了 J2 偏小——**单个 J_n 不能拿去和文献比，
必须和 J0、D 一起看**。

一个旁证：用文献那套 J 做自旋动力学，Tc = 919 K（cond-mat/0501713）；本文模型
SLLG 给出 Tc = 912 K。两条完全不同的交换参数集给出同一个 Tc，正是因为 J0 相同。

至于"为什么 J2 几乎没有"：NEP 的五个描述符（Sex/San/Sdm/Sia/Smag）是多体标量，
它的"交换常数"是把角向能量投影到 6 个壳层上的**有效傅里叶分量**，不是成对跳跃积分；
壳层分解不唯一，多体项可以被吸收进不同的壳。拟合残差只有 0.41 meV/atom 说明这个
投影对这个势是自洽的，但不能据此说"这个势的第 2 近邻交换是 2.2 meV"。

### 15.8 一个仍然存在的限制：区界处的磁子能量

* 用文献那套 J（J1=36.3, J2=20.7, J3=−1.6, J4=−2.4）按同一公式外推到 H 点，
  也给出 **约 512 meV**；
* 实测色散在区界明显"压平"，是巡游电子（非双线性）效应，六壳层 Heisenberg 形式
  无论怎么拟合都给不出这个压平。

所以：**小 q 的刚度 D 是可信的（292–310，与实测一致），区界附近的大 q 磁子能量不可信。**
要算有限的 q 的磁子热输运/散射，只能用 $q \lesssim 0.3\ q_{ZB}$ 的部分。这一条在
做磁声热导之前必须写进适用范围。

## 16. 为什么"之前的 J 符合实验、现在反而不一致"——溯源与澄清

### 16.1 先看之前的数

父目录 `GPUMD-spin/round2/第2轮_全流程验证报告.md` §3.7 给的是（`round2/results/v07_exchange.json`）：

| 体系 | 壳 r/z | J (meV, 单位矢量约定) | J/m² (meV/μB²) | J₀=ΣzJ | rmse |
|---|---|---|---|---|---|
| Fe | 2.467/8 | 64.520 | 10.323 | 451.0 | 0.70 meV/at |
| Fe | 2.849/6 | 3.512 | 0.562 | | |
| Fe | 4.029/12 | −6.135 | −0.982 | | |
| Fe | 4.725/24 | 0.987 | 0.158 | | |
| Fe | 4.935/8 | −4.544 | −0.727 | | |

同表给的"参考"是**由 T_C 反推的 350–450 meV**，判"**量级一致**；拟合 quality=0.009"。
注意：**这一行比的是 J₀，不是 J₁**；而且 J₁=64.52 甚至比现在的 55.5 还大。

第 2 轮的磁子谱脚本 `round2/scripts/v10_magspectrum.py` 第 9–10 行与第 122–123 行：

```python
# hbar*omega(q) = 2 [E(q)-E_FM] / (N * S)      (S = m_muB/2, g=2)
S  = m / 2.0
hw = 2.0 * dE / S                 # meV
```

**这是正确的关系（除以 S）。** 所以第 2 轮给出 D = 254 meV·Å²（实验 280，−9.2%），
"符合实验"的其实是 D 和 J₀，不是 J₁。

### 16.2 现在为什么"不一致"

两件事，性质完全不同：

**(a) 比较的量和参考都换了（表象）。** 第 2 轮比 **J₀ = 451** 对 **Tc 反推的 350–450**；
本轮 §15 比 **单个 J₁ = 55.5** 对 **KKR 的 36.34**。J₀ 与 J₁ 是两个量，参考值来源也不同。
用第 2 轮那条判据，本轮模型 J₀ = 430 meV（同一约定、同一磁矩）仍在 350–450 内。

**(b) 磁子→频率的换算在 V3 被改坏了（真错误）。** 第 2 轮是 `2ΔE/(N·S)`；V3 阶段 C 重写时
写成 `2S·ΔE/N`，把 S 从分母挪到分子，D 因此被放大 S²=1.49：254 → 345 → 433，于是判
"D 偏硬 FAIL"。**这是 V3 引入的回归，不是模型变差**，已在 §15 修回。

### 16.3 控制变量：同一个模型上比两种方法

用**第 2 轮的模型**（`round2/logs/Fe.nep.txt`，a0=2.849 Å）重跑本轮的螺旋拟合：

| 量（同一模型） | 第 2 轮共线构型拟合 | 本轮冻结螺旋拟合 | 差 |
|---|---|---|---|
| J₁（单位矢量，m=2.5） | 64.52 | 50.01 | −22% |
| J₂ | 3.51 | 14.12 | +302% |
| J₃ | −6.14 | 0.19 | 变号 |
| **J₀ = Σz_nJ_n** | **451** | **430** | **−5%** |
| **D（修正后关系）** | **254** | **251** | **−1%** |

结论很清楚：**两种拟合基组给出的 J₀ 和 D 一致到 5% 以内，但壳层分解差很多**
（J₁ 差 22%、J₂ 差 3 倍）。共线构型只采样 q=0 和区界的几种共线序，螺旋则连续扫 q；
壳层之间高度相关，所以"J₁ 是多少"本身就带 ±30% 的方法不确定性，而 J₀、D 不是。

### 16.4 换模型：重训到底改了多少

各自在自己的弛豫 a0 上、把自旋缩放到实验磁矩 2.2 μB 重拟合（唯一可比的口径）：

| 量（@2.2 μB） | 第 2 轮模型（2026-10-16） | 本轮 500k 模型 | KKR 文献 |
|---|---|---|---|
| J₁^S (meV) | 39.2 | **41.4** | 36.34 |
| J₂^S | 6.2 | 2.2 | 20.65 |
| J₀^S (meV) | 319 | **315** | 337 |
| D (meV·Å²) | 279 | **291** | 212(截断) / 298(外推/实验) |
| 拟合残差 (meV/at) | 1.57 | **0.52** | — |

**两代模型的 J₁、J₀、D 几乎一模一样**（差 5% / 1% / 4%）。50 万步重训把这套交换
基本没动，改好的是拟合质量（残差 1.57 → 0.52 meV/at）和力误差。
真正的差别只有一处：**J₂ 从 6.2 降到 2.2**，交换更集中在最近邻——这也是 D 略升
（279→291）的原因，因为 D 的权重带 r²。

### 16.5 所以"和实验差得多"到底还剩多少

把口径统一（标准 Heisenberg 约定、实验磁矩、各自 a0、同一套拟合方法）之后：

* **J₁ = 41.4 vs 文献 36.3，+14%**；同一方法在第 2 轮模型上是 39.2（+8%）。
  而方法本身的不确定度约 ±30%（共线 vs 螺旋）。→ **J₁ 与文献是一致的，之前的"+53%"
  是拿"单位矢量约定 + 模型自身 2.44 μB"的 J_fit 去比"标准约定 + 2.2 μB"的文献值，口径错了。**
* **J₀ = 315 vs 337，−7%**（第 2 轮 319，同结论）。
* **D = 291 vs 实测 280–330，区间内**（第 2 轮 279，同结论）。
* 唯一真实且两轮都存在的差异：**J₂ 偏小**（2–6 vs 20.7），即这个势的交换比 DFT
  更"短程"。这解释了区界磁子能量偏高（§15.8），也解释了为什么 J₁ 略大而 D 只差几个百分点。

### 16.6 一句话

**J 从来没有和实验不一致过；变的是"拿 J₀ 比 Tc 反推值"改成"拿 J₁ 比 KKR"，
再加上 V3 自己把磁子换算的 S 挪错了位置。** 现在两处都已按正确口径重算：
J₁ +8…14%、J₀ −5…−7%、D 在区间内，唯一剩下的真实差异是 J₂ 偏小。

## 17. F-25（同一 `run.in` 里 NVT→NVE 在 $N\ge432$ "挂死"）：核查、根因与修复

### 17.1 先复现

复现条件按 `docs/theory/15` 的记载：`run.in` 里先 `ensemble nvt_lan` 跑一段，再
`ensemble nve` 跑一段； $N=432$ 与 $N=1024$ 各复现过，"进程存活、CPU 占用、26 分钟无输出"。
本轮的复现矩阵（模型 = 500k 权重，`time_step 0.05`）：

| 用例 | $N$=250 | $N$=432 | $N$=1024 |
|---|---|---|---|
| NVT 3000 + NVE 12000（一段文件） | rc=0，10 s | rc=0，10 s | rc=0，12 s |
| NVT+NVT / NVE+NVE / 单块 | rc=0 | rc=0（NVE+NVE 有一次被 guard 停） | rc=0 |
| 第二段 60000 步 | — | rc=0，105 s | — |
| 第二段自旋 T=0、NVT_ber、dt=0.1 等变体 | — | 全部 rc=0 | — |

**没有一次真正的挂死。** 但所有用例都出现同一个异常：`dump_thermo 100`、总步数 15000，
`thermo.out` 只写了 **31 行**（应该 150 行）。

### 17.2 根因在 measure，不在积分器

```cpp
// src/measure/measure.cu, r18
void Measure::post_run(...) {
  for (auto& action : actions_) action->post_run(...);
  actions_.clear();            // <-- 第一个 run 块结束，measure 全被销毁
}
```

`Perform_a_run()` 每次都以 `measure.pre_run()` 开始，但第一个 `run` 块结束时
`actions_` 被清空，第二个块拿到的是一张**空表**：积分照跑、stdout 照打进度，而
`thermo.out` / `traj.xyz` / `restart.xyz` 再也不会更新。

这正好解释三条历史观察：

* **"无任何输出"**：数据文件不动；stdout 若重定向到文件，`printf` 走块缓冲，
  1 KB 以下的内容长时间不落盘，肉眼看同样是"没输出"。
* **" $N\ge432$ 才复现"**： $N$ 越大单块跑得越久，越容易被提前判死。这不是 $N$ 的物理阈值，
  是"等多久"的阈值—— $N=128$ 只是先跑完了。
* **"拆成两次调用就好"**：每个进程都从自己的第一个 `run` 块开始，measure 是新的。

### 17.3 修法

只改 measure 层，不碰积分器、不碰物理：

1. `Measure::post_run()` 不再清空，而是把 **dump 类** action 保留下来
   （`dump_thermo`、`dump_xyz`、`dump_exyz`、`dump_netcdf`、`dump_restart`）。
   它们本来就是无状态追加写，`pre_run()` 以 `"a"` 重新打开文件。
2. `Dump_Thermo` 增加 `header_written_`，同一次进程只写一次表头，避免第二段在数据中间
   插一段 `# columns ...`。
3. **时间平均类 `compute_*` 仍然在段末总结并丢弃**：它们的累加器按段定义，静默续用会把
   两个不同的 ensemble 平均到一起，那是错误的物理。

### 17.5 仍然要说清楚的三条
