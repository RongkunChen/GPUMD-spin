# 例：保守动力学的能量守恒（dt 与时长扫描）

```bash
python nve_drift.py --dt 0.05 --ps 1.0
python nve_drift.py --dt 0.1  --ps 1.0
python nve_drift.py --dt 0.2  --ps 1.0
```

输出 `max|dE|/N`（判据 $<10^{-5}$ eV/atom）与末态漂移。

预期（1024 原子，250 K）：dt=0.05 → $\sim6\times10^{-8}$；0.1 → $\sim8\times10^{-8}$；
0.2 → $\sim1.2\times10^{-7}$（仍低于门禁，但比 0.05 高 54%，且强场小胞会失守）。
长时间漂移速率 4.6e-9 eV/atom/ps → 1e-5 门禁约在 2.2 ns。

**注意 1**：初速按 250 K 采样，但它只分给晶格；自旋–晶格弛豫后平衡温度会降到
约 125 K（能量在自旋与晶格之间重新分配）。报告里写的是平衡温度，不是初温。

**注意 2**：`alpha=0 T=0` 分支没有随机数，同一输入重复运行逐字节相同。
